# Reprendre une configuration dans Claude Code ou Codex

Proposer cette fiche si l’utilisateur change d’outil ou interrompt une configuration longue. La remplir avec ses décisions déjà validées. Indiquer « à confirmer » lorsqu’une information manque. Elle peut être collée au début d’une nouvelle conversation. Une demande de fiche écrite au disque suit le dossier choisi par la personne.

**Exemple fictif de fiche remplie**

| Élément | État au moment de la pause |
| --- | --- |
| Projet et surface | Annuaire de réparateurs de vélos, SaaS → Autopilot, site WordPress de démonstration |
| But du premier essai | Vérifier une fiche dans WordPress avant de préparer les autres |
| Validé | Titres saisis manuellement, type Articles, statut Brouillon |
| À confirmer | Compte auteur réellement proposé dans le sélecteur |
| Préférence de la personne | Un réglage à la fois, sans recommandations commerciales |
| Prochaine action | Ouvrir le sélecteur Auteur, relever le nom affiché et vérifier la signature après le premier brouillon |

Au tour de reprise, repars de la prochaine action. Si la personne change de site, de langue ou d’objectif, indique quels choix demandent une nouvelle vérification. Exclure de la fiche les clés, les données de prospects et les identifiants de connexion.
