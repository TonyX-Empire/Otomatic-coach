# Lire une ancienne interface Otomatic

Les guides du plugin datés de décembre 2025 décrivent surtout le couple WordPress + SaaS, les clés fournisseurs, le profil IA, l’assistant, les médias et la planification. Le relevé du plugin du 23 novembre 2026 situe plusieurs de ces tâches dans le SaaS. Quand une vidéo et le compte divergent, commence par identifier l’objectif du clic et la surface visible. Propose une valeur éditoriale même si le nouveau nom du bouton reste à confirmer.

| Indice dans un ancien tuto | Ce qu’il faut retrouver aujourd’hui |
| --- | --- |
| Installation du plugin ou écran WordPress | Vérifier l’extension associée au bon site, puis la destination éditoriale dans le SaaS. Une propriété de suivi permet d’observer des performances. Elle ne prouve pas que WordPress reçoit des articles. |
| « Mon prompt personnalisé » | Demander dans quelle rubrique il se trouve. Voix de la personne → profil rédacteur. Règle commune → domaine. Angle et faits propres à un article → assistant. Source ou rythme du lot → Autopilot. |
| Template enregistré | Vérifier le profil, le site et les réglages chargés sur le projet courant. Tester une entrée avant de réutiliser le modèle en série. |
| Tarif, modèle, limite ou exemple de variable | Vérifier sur l’écran ou dans une source officielle actuelle. Une variable vue dans un tutoriel ne prouve pas qu’elle sera interprétée dans un autre champ. |

**Exemple POE.** Une rédaction jardin souhaite publier des comparatifs à partir de fiches fabricants. La voix du rédacteur explique les termes aux débutants. La règle de domaine exige une source pour les caractéristiques techniques. Le brief de l’article donne les références et les critères de comparaison. Le projet Autopilot reçoit les titres validés et le statut Brouillon. Pour vérifier la répartition, modifier un titre d’essai et vérifier que le ton et l’exigence de sources restent adaptés au nouvel article.
